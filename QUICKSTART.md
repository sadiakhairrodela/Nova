# 🎯 QUICK START - Just 3 Commands!

## Prerequisites
✅ Database already imported (from database.sql)
✅ All code files created and ready

## Step 1: Install Dependencies & Start Backend

```bash
cd backend
npm install
npm start
```

Expected output:
```
✅ MySQL Database Connected Successfully!
╔════════════════════════════════════════╗
║   RODELA Backend Started Successfully  ║
╠════════════════════════════════════════╣
║ Server running on: http://localhost:5000  ║
╚════════════════════════════════════════╝
```

## Step 2: Install Dependencies & Start Frontend (NEW TERMINAL)

```bash
cd frontend
npm install
npm start
```

Expected output:
```
Compiled successfully!

You can now view rodela-frontend in the browser.

  Local:            http://localhost:3000
```

## Step 3: Open Browser

Go to **http://localhost:3000**
